# Codex 算力条使用说明

## 1. 它解决什么问题

Codex 算力条把常用额度和当天项目 Token 统计固定显示在 Codex 主窗口顶部，减少频繁进入详情页查看数据的操作。

默认紧凑状态：

```text
总 31% · 7月25日 · 4天 │ 5.3 86%
```

其中：

- `总 31%`：账户整体剩余用量。
- `7月25日`：整体额度重置日期。
- `4天`：距离整体额度重置的剩余天数。
- `5.3 86%`：GPT-5.3 单独额度的剩余用量。

## 2. 安装

### 环境要求

- macOS 13 或更高版本。
- Codex 桌面客户端或可用的 Codex CLI。
- Xcode Command Line Tools。

检查 Swift：

```bash
swift --version
```

首次安装：

```bash
git clone https://github.com/yidiandianzheng/codex-pet-energy.git
cd codex-pet-energy
swift run CodexPetEnergy --self-test
./scripts/install-app.sh
open "$HOME/Applications/Codex算力条.app"
```

安装脚本会从源码构建，将应用放到：

```text
~/Applications/Codex算力条.app
```

应用使用本机临时签名。若 macOS 首次拦截，可在 Finder 中右键应用选择“打开”，或前往“系统设置 → 隐私与安全性”确认本次打开。

## 3. 基本交互

- 左键按住并移动：拖动算力条。
- 左键单击：不会展开任何详情。
- 右键：打开功能菜单。
- “查看项目算力”：展开当天最近活跃的 5 个项目。
- “查看剩余用量”：展开完整额度和重置信息。
- 再次选择对应关闭项：收起详情。
- “恢复默认位置”：回到顶部留白区的默认居中位置。
- “退出算力条”：结束应用。

拖动后的位置会自动保存，并继续以 Codex 主窗口为基准跟随。

## 4. 颜色含义

- 绿色：剩余 50%–100%。
- 黄色：剩余 20%–49%。
- 红色：剩余 0%–19%。
- 灰色 `—`：数据暂时不可读。

GPT-5.3 使用明确的 `5.3` 蓝色文字标记，因此无需只靠颜色识别模型。

## 5. 登录自动启动

默认关闭。开启：

```bash
./scripts/enable-login-item.sh "$HOME/Applications/Codex算力条.app"
```

关闭：

```bash
./scripts/disable-login-item.sh
```

## 6. 更新

进入仓库目录后执行：

```bash
git pull
swift run CodexPetEnergy --self-test
./scripts/install-app.sh
```

退出旧进程并重新打开应用：

```bash
pkill -x CodexPetEnergy || true
open "$HOME/Applications/Codex算力条.app"
```

## 7. 常见问题

### 算力条没有出现

依次检查：

1. Codex 主窗口是否位于前台、未隐藏、未最小化。
2. 应用进程是否存在：

   ```bash
   pgrep -fl CodexPetEnergy
   ```

3. 自测是否通过：

   ```bash
   swift run CodexPetEnergy --self-test
   ```

### 额度显示 `—`

表示本机暂时无法读取对应额度。应用会自动重连；不会用其他模型数据替代 GPT-5.3。

### 项目列表为空

项目统计只读取上海时区当天存在 Token 记录的 Codex 会话。当天尚未产生记录时，列表为空是正常情况。

### 为什么项目 Token 与账户额度百分比不能直接换算

两者来源和计量方式不同。项目 Token 是本机会话统计，账户额度是 Codex 返回的账户额度桶；本项目不会把账户百分比强行分摊到单个项目。
